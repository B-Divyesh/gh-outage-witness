# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/) and
this project uses semantic versioning.

## [Unreleased]

## [0.1.1] - 2026-08-28

### Fixed

- Made the public GitHub CLI extension name, binary, and install command agree.
- Redacted complete quoted sensitive assignments, including values with spaces.
- Restricted incident ZIP files to the owner on Unix, including forced replacements.
- Made mobile command scrollers keyboard-focusable and all footer links at least 44px.

## [0.1.0] - 2026-08-28

### Added

- Read-only capture of Actions run, jobs, attempt lineage, logs, and public
  GitHub Status observations.
- Local self-hosted runner diagnostic attachments.
- Built-in and configurable redaction with a share-safety report.
- Conservative code, runner, platform, and inconclusive evidence labels.
- JSON automation output, strict partial-evidence mode, and static docs site.
