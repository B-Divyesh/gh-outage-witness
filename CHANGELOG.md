## [0.1.0] - 2026-08-28

### Added

- Read-only capture of Actions run, jobs, attempt lineage, logs, and public
  GitHub Status observations.
- Local self-hosted runner diagnostic attachments.
- Built-in and configurable redaction with a share-safety report.
- Conservative code, runner, platform, and inconclusive evidence labels.
- JSON automation output, strict partial-evidence mode, and static docs site.
