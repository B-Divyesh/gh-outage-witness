Privacy for local incident bundles

The CLI runs locally. The site has no tracking. Your incident bundle stays under your control.

CLI data

CI Outage Witness reads the Actions run you identify through GitHub’s API. It uses GET requests and never changes or retries the run.

Runner files are read only when you pass them with --runner-log. The CLI writes one ZIP to the path you choose.

On Unix, that ZIP uses owner-only permissions. The CLI has no server, account system, telemetry, or automatic upload.

Authentication

The CLI can read a token from GH_TOKEN, GITHUB_TOKEN, or your local GitHub CLI session.

It sends that token only to your configured GitHub API host. It never sends the token to the public status endpoint.

The token is not written into the bundle.

Redaction and sharing

Known credential formats, sensitive assignments, private key blocks, and configured patterns are replaced before files enter the bundle.

Pattern matching cannot identify every unusual secret. Review every bundle before sharing it.

Documentation site

This site uses no cookies, analytics, advertising, fingerprinting, forms, or third-party runtime requests.

A service worker stores public site files on your device for offline use.

The demo stores only its selected sample under a demo: key. Reset demo replaces that sample with the original.

Clear this site’s browser storage to remove the sample and cache.

Third parties and contact

GitHub handles API requests under its terms when you run the CLI. The public status observation comes from githubstatus.com.

Open privacy questions in the project repository. Never include an incident bundle or secret in a public issue.
